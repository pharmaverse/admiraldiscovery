# Report Package Versions

Function returns a string listing the packages and their versions.

## Usage

``` r
admiral_pkg_versions()
```

## Examples

``` r
admiral_pkg_versions()
#> admiral v1.5.0, admiralonco v1.4.1, admiralophtha v1.5.0, admiralvaccine v0.6.0, admiralmetabolic v0.3.0, and admiralneuro v0.2.1
```
