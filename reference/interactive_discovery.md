# Interactive Admiral Function Discovery

Interactively explore admiral functions and the ADaM data sets and
variables they help create.

## Usage

``` r
interactive_discovery(type = c("gt", "reactable"))
```

## Arguments

- type:

  type of table to return

## Value

interactive gt table

## Examples

``` r
if (FALSE) {
interactive_discovery("gt")
interactive_discovery("reactable")
}
```
